# Project Roadmap

## Phase 1 - Foundation

Complete: Next.js, TypeScript, Tailwind CSS, accessibility primitives, static
export, formatting, linting, and documentation.

## Phase 2 - Production architecture

In progress: all required public routes, centralized content, approved brand
assets, SEO defaults, structured data, empty states, and source documentation.

## Phase 3 - Leadership content review

Requires NETYR approval of leaders, events, contact methods, payment links,
community partner names, photos, news, and legal language.

## Phase 4 - Release candidate

- Replace all launch-blocking placeholders.
- Test real external links and downloads.
- Perform keyboard, screen-reader, responsive, and browser review.
- Run Lighthouse and resolve material issues.
- Review the GitHub Pages workflow without running a deployment.

## Phase 5 - Production launch

- Approve the final pull request.
- Merge through the agreed review workflow.
- Configure the custom domain in GitHub Pages only after explicit approval.
- Verify sitemap, robots, headers, analytics decisions, and post-launch contact
  flows.
